
# Photography Learning App

A responsive photography learning web app built with React and Vite. The project presents beginner-friendly camera techniques through structured category pages, image galleries, and an interactive exposure triangle simulator. It also includes a navigable techniques menu, organized content for composition and lighting concepts, and a clean UI designed to make photography fundamentals easy to explore on desktop and mobile.
